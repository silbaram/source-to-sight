# 유지보수 문서 시각 검증

처음 프로젝트를 접하는 사람이 **프로젝트 구성·기능 요약 → 세부 처리·분기 → 선택한 처리의 규칙 그림**을 따라 이해할 수 있는지 검토하는 HTML 문서입니다.

[개선된 프로젝트 문서 열기](source-to-sight-maintainer/project.html) · [UI/UX 구성 기준](ux-review.md)

최상단에는 실행 환경·패키지·저장 파일·브라우저를, 아래에는 기능별 요청·결과와 2~3개의 역할 요약을 보여 줍니다. 역할 박스는 해당 기능의 세부 처리 목록으로, 처리 노드는 관련 규칙 그림으로 연결됩니다. 지도에서 상세 그래프를 반복하지 않습니다.

저장소를 내려받은 뒤 위 `project.html`을 브라우저에서 엽니다. 지도 1개, 기능 흐름 5개, 규칙 설명 5개가 상대 경로로 연결되어 있으므로 `source-to-sight-maintainer/` 디렉터리를 통째로 유지합니다. 별도 서버나 인터넷 연결은 필요하지 않습니다.


확인 범위는 데스크톱 1440px·모바일 390px의 밝은·어두운 테마입니다. 5개 기능의 규칙 11개를 네 화면 조건에서 탐색하는 44개 경로를 확인합니다. 같은 화면의 역할 요약과 해당 역할의 세부 처리 목록, 선택한 노드에 연결된 그림, 조건 비교 동작, 돌아올 때의 기능·선택 복원, 페이지 가로 넘침과 외부 네트워크 요청 여부를 검사합니다.

이 HTML은 생성 시점의 소스와 설명을 담은 검토용 스냅샷입니다. 화면 템플릿과 생성 코드는 `skills/`에서 관리하며, 이후 코드 변경이 이 문서에 자동 반영되지는 않습니다. 재생성용 원본은 로컬의 `build/source-to-sight-maintainer/_internal/project/`에 보관하고 Git에 포함하지 않습니다. 보관 기준은 [배포 파일 기준](../docs/distribution.md)을 참고하세요.
