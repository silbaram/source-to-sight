| 문제 | 수정과 확인 |
| --- | --- |
| P1: `s2s.py render`가 입력 JSON을 덮어쓰고 성공 | 입력·HTML·render JSON의 경로 충돌과 심볼릭/하드 링크 별칭을 쓰기 전에 거부한다. `author.py build`와 보호 함수를 공유한다. 같은 대상 HTML의 재생성은 허용하고 다른 대상·범위·저장소·계층·언어의 HTML 교체는 거부한다. 충돌 후 원본과 기존 출력의 바이트가 유지되는지 검사했다. |
| P2: 활성 상세 12개 중 6개에 지도 복귀 링크 누락 | 지도는 이 지도로 돌아오는 활성 링크까지 확인한다. 복귀 링크가 없는 기존 HTML은 생성 요청으로 남기며 임의로 다시 쓰지 않는다. 평가 목록에 기존 상세 입력 6개를 명시해 지도와 함께 조립했고, 12개 기능 모두 화면의 복귀 버튼으로 돌아오는지 검사했다. |
| P2: 화면 크기 변경 후 복귀 시 선택 노드 이탈 | 저장 좌표에 화면·캔버스·그래프 크기를 함께 기록한다. 같은 배치에서는 확대·스크롤을 복원하고, 배치가 달라졌거나 크기 정보가 없는 이전 링크는 선택한 기능·구역을 유지하면서 노드를 다시 맞춘다. 1440×1000→390×844와 390×844→844×390을 검사했다. |
| P2: 평가 저장 실패 후 자동 성공 상태 유지 | 예외 처리에서 자동·최종 평가 상태를 모두 실패로 바꾼다. 지도 검토 양식 저장에만 `OSError`를 주입해 오류 기록, 해당 사례와 전체 보고서의 실패, 종료 코드 1을 확인했다. 나머지 35개 사례는 자동 통과했다. |

기존 동작·규칙 30개 후보와 전체 36개 검증 기준의 해시는 유지했다. 기존 30개를 M4 기록과 비교하면 `no-regression`이다. M5 전체의 평가 목록에는 상세 입력 6개가 추가되어 이전 M5 목록과의 비교 명령은 `incomparable`로 보고한다. 이를 같은 평가 구성에서의 성능 개선으로 해석하지 않는다. 추가 상세는 기존 동작 평가 사례이며 새로운 독립 생성 사례로 세지 않는다.
