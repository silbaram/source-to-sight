# 공통 캔버스 UI 적용 및 검증

2026-09-06 · 실제 HTML 생성 경로 적용

## 원인과 수정

승인된 화면은 디자인 시안인 `plans/design/atlas-prototype.html`에만 구현되어 있었고, 실제 `s2s.py render`와 `author.py build`는 `skills/code-flow/templates/`의 이전 화면을 사용했다. 생성된 HTML은 스타일·스크립트를 포함하는 정적 파일이므로 시안을 수정하거나 새로고침하는 것만으로 바뀌지 않았다.

공통 생성 템플릿의 HTML·CSS·JavaScript에 승인한 캔버스 디자인과 다크모드를 적용했다. M0 예시 11개와 M1 실제 소스 사례 6개를 이 경로로 다시 생성했다. 시안의 가상 프로젝트·좌표는 가져오지 않고 기존 IR, Dagre 자동 배치, 근거 검증을 사용한다.

## 실제 출력의 동작

- 구성 보기로 시작하며, 왼쪽 목록과 검색에서 실제 노드의 이름·역할·식별자를 찾는다. 상세 노드도 검색으로 열 수 있다.
- 순서가 있는 시나리오에만 흐름 전환과 단계 제어를 제공한다. 자동 재생은 사용자가 시작하며, 마지막 단계나 수동 탐색에서 멈춘다.
- 지도를 드래그하거나 키보드·스크롤로 이동하고 확대·축소·전체 맞춤을 사용할 수 있다. 터치에서는 기본 스크롤을 유지한다. 큰 그래프의 최초 화면은 글자 크기를 확보하기 위해 일부 영역이 화면 밖에 있을 수 있다.
- 선택하면 역할·행동·상태 조건·원본 위치가 담긴 패널이 열린다. 모바일은 하단 패널이다. 선택 노드는 데스크톱 패널 옆이나 모바일 패널 위의 가시 영역으로 이동한다. 구성 보기에서 핵심/상세를 전환해도 남아 있는 노드·연결선의 선택과 설명을 유지하며, 숨겨지는 대상은 선택과 패널을 닫는다. 관계 집중은 관련 없는 부분을 흐리게 한다. 다른 노드나 근거 항목을 선택하면 이전 강조를 해제하며, 검색·목록·키보드 선택에도 같은 규칙을 적용한다. 상단에 강조 기준 노드를 표시하고, 같은 노드의 패널에서는 “연결 강조 해제”를 제공한다. 보기 전환과 흐름 단계 이동에서도 강조를 해제한다. 돌아가기는 같은 페이지의 보기·단계·상세 수준·선택·카메라를 복원한다.
- 다크모드는 그래프·화살표·근거 패널에도 적용된다. 선택을 저장하며, 로컬 저장소를 사용할 수 없어도 전환과 탐색은 동작한다.
- `behavior`는 “설명 범위의 구성”으로 표시한다. UI를 공유해도 프로젝트 전체를 분석했다는 뜻이 되지 않는다.

## 확인 결과

| 검사 | 결과 |
| --- | --- |
| `npm run fixtures` | M0 HTML 11개 재생성, 기존 링크·근거 검증 유지 |
| `npm run m1:examples` | M1 HTML 6개 재생성, 원본 근거 22개 재확인 |
| `npm test` | 45개 통과 |
| `npm run test:browser` | 100개 통과: 렌더러 50개 + M1 16개 + 캔버스 상호작용 34개 |
| Chromium 1440×1000 / 390×844 | 오프라인·외부 요청 없음·문서 가로 넘침 없음, 노드 겹침·무관한 노드 관통·화살표 접점 검사 |
| 캔버스 상호작용 | 초기 패널 숨김, 검색과 상세 노드 근거, 다크모드 저장·저장소 차단, 관계 집중/복귀, 선택 변경 후 강조 해제·새 선택 표시, 같은 노드의 강조 해제, 패널 가림 없는 선택·확대, 핵심/상세 전환 시 선택 유지·숨김 처리, 키보드 이동·전체 맞춤 |
| 시각 확인 | 실제 에이전트 결과의 밝은/어두운 화면, 실제 라이브러리·이벤트 결과의 근거 패널 확인 |

확대 후 연결선 검사는 SVG의 화면 변환 행렬을 사용해 노드 경계와 비교한다. 모든 생성 페이지에 `data-viewer="canvas"`가 있는지 검사하여 이전 화면이 다시 사용되는 문제를 감지한다. 자동 검사는 소스 본문 비노출과 HTML 형태 문자열의 무해성도 계속 확인한다.

추가 코드리뷰에서 확인한 ID 충돌은 Dagre에 전달하는 노드·연결선 ID를 내부 전용 값으로 변환해 수정했다. `constructor`, `toString`, `valueOf` 등과 내부 접두사처럼 보이는 원본 ID를 포함하는 그래프를 실제 렌더러로 생성하여, 데스크톱·좁은 화면에서 배치·자기 연결·근거·검색·관계 집중/복귀·다크모드·흐름 이동을 검증했다. 원본 IR 식별자는 화면 상호작용과 근거 연결에 유지된다.

## 적용 범위

새 결과는 공통 템플릿으로 생성한다. 이미 만들어 둔 HTML에는 자동 업데이트 기능이 없으므로 해당 생성 명령을 다시 실행해야 한다. 설치 시 복사한 스킬을 사용하는 경우 그 스킬의 템플릿도 현재 버전이어야 한다.

프로젝트 전체 탐색(M5), 페이지 간 카메라 복원, 복합 구역 접기, 핀치 확대, 대규모 그래프 성능은 이번 적용 범위에 포함하지 않는다. M1 사람 검토 게이트와 독립적인 이해도 검토도 대기 중이다. [렌더러 계약](../../skills/code-flow/references/renderer-contract.md)과 [M1 검증 기록](m1-verification.md)에 각 범위가 기록되어 있다.
