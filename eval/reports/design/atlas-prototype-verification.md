# 프로젝트 지도 시안 검증

2026-09-06 · [검토 문서](../../../plans/design/project-atlas-ux-review.md) · [인터랙티브 시안](../../../plans/design/atlas-prototype.html)

검증 대상은 가상 데이터로 만든 디자인 시안이다. 실제 분석기·렌더러·IR을 변경한 결과가 아니며, 기존 M0 검증 결과에 포함하지 않는다. 이후 공통 생성 템플릿에 적용한 결과는 [캔버스 적용 기록](../canvas-viewer-verification.md)에서 별도로 확인한다.

## 브라우저 검토

설치된 Playwright의 Chromium에서 로컬 `file://`로 열어 확인했다.

| 조건 | 결과 |
| --- | --- |
| 데스크톱 1440 × 960, 일반 모션 | 통과 |
| 좁은 화면 390 × 844, 모션 감소 | 통과 |
| AI 에이전트 6개 요소 / 프레임워크 5개 요소 | 공통 UI로 전환, 구성과 흐름 노출 |
| 유틸리티 2개 독립 요소 | 관계선 0개, 흐름 전환·재생 숨김 |
| 목록에서 키보드로 요소 선택 | 상세 열기, Escape 닫기, 원래 항목으로 포커스 복귀 |
| 검색과 빈 검색 결과 | 일치 항목 표시·선택, 일치 항목 없음 안내 |
| 관계 집중과 돌아가기 | 범위 전환·복귀 동작 |
| 설명 이전/다음/자동 넘김 | 설명·단계·연결 강조 전환, 일시정지 |
| 모션 감소 | 활성 연결의 CSS 애니메이션 없음 |
| 버튼·방향키·드래그로 지도 조작 | 확대·축소·맞춤·이동 동작 |
| 범위 패널 | 샘플임을 명시, 항목용 관계 집중 버튼 숨김 |
| 문서 가로 넘침 / JavaScript 오류 / 외부 HTTP 요청 | 없음 |

마지막 배치 조정 후에는 현재 단계의 노드가 완전한 불투명도로 강조되는지 재확인했다. 작은 화면에서 상세 패널을 열면 선택한 노드를 패널 위에 배치하고, 패널을 닫으면 검색 결과에 포커스가 복귀하는지도 확인했다.

다크 모드 추가 후 1440px·390px·320px 화면에서 클릭 및 키보드 전환, 켜짐·꺼짐 각각의 새로고침 복원, 프로젝트 유형 전환, 현재 설명·선택 패널·지도 위치 유지를 확인했다. 저장소 접근을 차단한 브라우저에서도 화면 렌더링과 테마 전환이 정상 동작했다. 가로 넘침과 JavaScript 오류는 없었다. 지도·노드·패널·하단 도구 영역의 밝은/어두운 색상을 확인하고 스크린샷을 검토했다.
