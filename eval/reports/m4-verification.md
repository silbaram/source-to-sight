배속·단계 바로 선택·키보드 탐색·모바일 설명 패널 크기 조절·현재 위치 링크를 구현했습니다. **S4.1–S4.5 구현과 자동 검증을 완료했으며**, 기존 동작 24개와 규칙 6개를 보존했습니다. 독립적인 사람의 사실·이해도 검토와 승인 베이스라인은 계속 대기 중입니다.

작성 도구 버전은 0.5.0입니다. 스키마와 분석 사실은 변경하지 않았습니다. M4는 현재 공통 캔버스 템플릿에 적용되며 새 동작 페이지와 재생성한 기존 페이지가 같은 기능을 사용합니다. M3 규칙 페이지는 기존 그림·조건 비교 방식을 유지하고 같은 폴더의 최신 동작 페이지와 연결됩니다.

## 동작 세부 기준

1× 기준 단계 시간은 1.5초, 연결 이동 시간은 1.1초입니다. 배속은 둘의 공통 설명 시간을 조절합니다. 360ms 카메라 이동은 같은 속도를 유지하며 단계 시간에 포함되지 않습니다. 재생 중 속도를 바꿔도 진행을 처음부터 다시 시작하지 않고, 일시 정지 상태의 속도 변경도 재생을 시작하지 않습니다. 직접 단계 선택과 키보드 단계 이동은 기존 타이머를 취소합니다.

URL은 `#s2s=1` 형식과 안정적인 대상·노드·시나리오·단계 ID를 사용합니다. 표시 문구나 단계 번호만으로 오래된 대상을 추정하지 않습니다. 현재 파일의 출력 데이터에 없는 참조, 중복 매개변수, 잘못된 속도·보기 또는 다른 대상은 복원하지 않습니다. 일반 문서 앵커는 그대로 사용할 수 있습니다. 자동 갱신은 브라우저 기록을 매 단계 늘리지 않으며, 복사한 링크는 같은 HTML 파일이 있어야 열 수 있습니다. 파일을 업로드하거나 공개하는 기능은 아닙니다.

클립보드가 거부되면 링크를 선택해 복사할 수 있는 입력란을 보여 줍니다. URL 갱신이 거부된 환경에서도 현재 상태로 복사할 링크를 만듭니다. 입력란을 닫으면 원래 복사 버튼으로 키보드 초점을 돌려줍니다.

전용 검사는 제어한 브라우저 시계로 세 속도의 단계·연결 시간을 확인하고, 중간 속도 변경·정지·재개·카메라 이동 중 변경을 재현합니다. 단계 바로 이동으로 이전 재생이 되살아나지 않는지, 60단계 설명의 마지막 단계로 바로 이동하고 다시 열 수 있는지도 확인합니다. 60단계 파일은 합성 UI 검증이며 소스 분석 사례나 관찰한 실행으로 집계하지 않습니다.

여섯 유형의 모든 복합 시나리오에서 같은 단계·속도 조작과 URL의 대상 ID를 확인했습니다. 최소 유틸리티와 순서 없는 프레임워크 설명은 단축키나 잘못된 링크로 재생 UI를 만들지 않습니다. 키보드 노드 이동·근거 열기·초점 복귀, 검색창·선택 목록·IME 보호, 상세 노드 링크, 해시 이동, 잘못된 대상 안내와 모션 없는 정보 동등성을 검사했습니다. 모바일 버튼과 본문은 화면 안에 있고, 새 크기 조절도 기존의 짧은 화면·회전·패널 경계 검사와 함께 통과했습니다.

## 확인할 결과와 재현

최신 결과는 `build/eval/m4/agent-parallel-tools.html`입니다. **흐름 따라가기**에서 **단계 선택**과 **설명 속도**를 사용합니다. **현재 위치 링크 복사** 또는 노드 설명의 **링크**로 같은 위치를 다시 열 수 있습니다. 모바일에서는 설명 패널의 **설명 확대 / 그림 더 보기**를 확인합니다.

~~~sh
npm run eval:rules -- --output build/eval/m4-next
S2S_EVAL_DIR=build/eval/m4-next npm run test:browser
npm test
npm run eval:compare -- build/eval/m3/results.json build/eval/m4-next/results.json
~~~

재실행은 새 출력 경로를 사용합니다. 현재 `build/examples/` 11개와 `build/m1/` 6개도 0.5.0 공통 템플릿으로 재생성했습니다. 이전 `build/eval/m3/`와 검토 답변은 보존했습니다. `build/eval/m4-draft/`는 개발 중간 결과입니다. 전체 HTML·스크린샷·로그는 Git에서 제외되는 build에, 선택한 실행 기록과 위 화면은 eval에 보존합니다.

새로운 소스 탐색이나 대상 프로그램·모델 API 실행은 수행하지 않았습니다. 이번 변경은 이미 작성된 설명의 탐색·재생 UI이며, 기존 30개 후보의 사실과 정답 기준을 그대로 재검증했습니다. 사람 검토를 자동 검사로 대신하지 않습니다. 다음 구현 범위는 M5의 프로젝트 전체 지도와 관심 기능으로 내려가는 탐색입니다.
