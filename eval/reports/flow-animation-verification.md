# 재생 중 연결 이동 애니메이션 — 2026-09-06

자동재생 단계의 출발점에서 도착점으로 작은 표시가 이동하고 도착 노드가 잠깐 반응하도록 공통 템플릿을 수정했습니다. 재생 영역에는 양 끝의 이름, 연결 설명과 근거 상태를 표시합니다. 기존 점선 이동 효과를 실제 SVG 경로 위의 이동 표시로 교체했습니다.

## 표현 범위

- 확인된 단계와 확인된 호출·전달·읽기·쓰기·이벤트·전환·위임 관계에 적용합니다. 표시의 방향은 기존 관계선의 방향입니다. 읽기 요청 같은 관계 방향과 실제 반환 데이터의 방향을 바꾸어 해석하지 않습니다.
- 등록·의존 관계와 추정·위치 미확인 연결은 정적 강조로 유지합니다. 미확인 연결의 화살표와 라벨은 선택 중에도 해당 색상·상태를 유지합니다.
- 노드로만 구성된 설명은 직전 단계에서 현재 단계로 향하는 확인된 연결이 정확히 하나 있을 때 사용합니다. 없는 호출, 역방향 반환, 여러 후보 중 임의 선택, 같은 노드의 반복을 새 흐름으로 만들지 않습니다.
- 순서가 없는 설명에는 재생을 추가하지 않습니다. 애니메이션은 설명을 돕는 표현이며 실제 실행·이벤트 수·소요 시간을 측정한 기록이 아닙니다.

## 동작

각 단계는 마지막 단계까지 1.5초 동안 표시합니다. 이동은 약 1.1초이며 도착 강조 후 다음 단계로 진행합니다. 한 단계짜리 시나리오도 한 번 재생하고 종료합니다. 일시 정지, 수동 선택, 시나리오·보기 변경, 페이지가 숨겨지는 경우 이동 표시를 정리합니다.

재생할 때 현재 연결의 양 끝과 경로를 지도 안에 맞춥니다. 모바일에서 하단 재생 버튼을 누른 직후 지도 밖에서 애니메이션이 시작되던 경우도 보완했습니다. 창 크기 변경으로 SVG가 재배치되어도 현재 단계의 경과 시간과 새로운 경로를 사용합니다.

운영체제의 동작 줄이기가 켜져 있으면 이동 표시·도착 효과를 생략하고, 선·방향·이름·상태와 단계 진행을 유지합니다. 재생 중 설정이 바뀌어도 즉시 반영합니다.
