# 상세 패널의 화면 이탈 수정 — 2026-09-06

사용자가 `build/eval/m15/web-dispatch.html`의 긴 근거 패널이 화면 밖으로 나가는 문제를 보고했습니다. 생성된 HTML에 포함되는 공통 템플릿을 수정하고, M0 11개·M1 6개·M1.5 18개 결과를 다시 생성했습니다.

## 원인과 수정

기존 데스크톱 패널은 다이어그램 열의 위에서 76px 떨어진 위치에 최대 600px 높이로 배치되어 지도 영역을 넘어갈 수 있었습니다. 패널 전체가 스크롤되어 닫기와 연결 강조 버튼도 함께 사라졌습니다. 실제 1000×500 창에서 패널 위쪽은 -100px, 닫기 버튼은 -75px 부근에 있었고 연결 강조 버튼은 화면 아래에 있었습니다. 모바일에서도 긴 내용 뒤의 연결 강조 버튼이 처음 보이는 패널 아래에 있었습니다.

- 데스크톱 패널을 캔버스 안에 배치하고, 지도와 화면에서 사용할 수 있는 높이에 맞췄습니다. 지도 하단 조작부를 덮지 않으며 페이지 스크롤과 창 크기 변경에 대응합니다. 지도를 화면 밖으로 스크롤하면 패널도 지도와 함께 이동합니다.
- 상태·닫기 영역과 연결 강조 버튼을 본문 스크롤에서 분리했습니다. 근거 목록만 스크롤하며 마지막 항목의 복사 버튼까지 접근할 수 있습니다.
- 새 대상을 선택하면 내용 배치가 끝난 뒤 본문 스크롤을 맨 위로 돌립니다. 이전 목록의 브라우저 스크롤 앵커가 새 설명에 남는 경우도 수정했습니다.
- 모바일 하단 패널은 동적 화면 높이 제한을 유지하고, 데스크톱에서 넘어올 때 이전 위치·높이 값을 해제합니다.
