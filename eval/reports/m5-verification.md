`codebase-atlas`의 저장소 탐색 지침, 책임 구역·기능 목록, 선택한 상세 페이지 조립과 **지도↔동작↔규칙 이동**을 구현했다. 실제 여섯 유형에서 새 지도를 만들었으며, 기존 동작 24개·규칙 6개는 보존했다. S5.1–S5.4 구현과 S5.5의 자동·시각 검증을 수행했다. 독립적인 사람의 사실·이해도 검토와 승인 베이스라인은 대기 중이다.

## 생성과 연결 계약

공유 code-flow가 설치되어 있으면 atlas 도구는 저장소의 개발 스크립트 없이 사용할 수 있다. 별도 설치 경로를 지정하는 테스트로 이를 확인했다. 규칙 페이지를 요청할 때만 visual-primer가 필요하다. 호스트가 읽고 검토한 내부 IR을 입력으로 사용하며 대상 프로그램이나 모델을 실행하지 않는다.

새 기능 목록은 기존 동작의 ID·kind·module·targets·scope와 일치해야 한다. 기존 label-only targets도 유지하되 코드 위치 근거를 명시하고, 생성 요청에 파일·심볼·줄 범위를 함께 넣는다. 기능의 불확실성이 담당 노드의 상태를 자동으로 바꾸지 않으며, 근거 없는 기능은 생략한다. 기존 최소 카탈로그도 공통 렌더러에서 읽을 수 있다.

요청한 모든 페이지의 내용과 목적지를 먼저 검증·렌더링하고 파일별로 교체한다. 디렉터리 전체의 원자적 교체는 아니다. 기존 파일의 대상·범위·언어·저장소 충돌, 출력 경로 중복, 내부 입력 파일 덮어쓰기를 거부한다. Atlas 연결은 양쪽 소스 근거가 현재 소스와 일치해야 활성화한다. 기존 동작↔규칙의 소스 불일치 경고 정책은 유지한다.

지도 복귀 상태는 URL에 담으므로 localStorage/sessionStorage가 없어도 동작한다. 이동 목적지는 상세 페이지에 검증된 지도 경로이며, 외부 입력으로 목적지를 선택하지 않는다. 잘못된 구역·대상·카메라 상태는 기본 화면과 안내로 처리한다. 복귀 시 자동재생하지 않는다.

전체 브라우저 검사는 `build/eval/m5/`에서 통과했다. 이후 평가 조립에서 HTML에 추가한 부모 링크를 각 render JSON에도 동기화하도록 보완했다. 공통 화면 코드는 그대로이며, 새 `build/eval/m5-final/`에서 36개 평가와 M5 브라우저 40개, 전체 HTML/JSON 일치를 재확인했다. 최종 엔진 해시는 보존 실행과 일치한다.

새 UI 검사는 여섯 지도의 실제 노드·관계·구역 수, 노드 겹침·구역 경계·구역 이름 겹침·본문 가로 넘침을 검사한다. 구역 진입/Back/전체 구성, 기능 검색과 초점 복귀, 미생성 명령 복사, 상세 수준 변경 시 선택 정리, 확대·모바일 패널 크기 변경 후 담당 노드 가시성, 저장소 접근 거부 상태의 세 계층 왕복과 정확한 카메라 복원을 포함한다. 개발 중 발견한 모바일 구역 이름 겹침과 확대율 반올림에 의한 복귀 오차도 수정했다.

기존 재생·배속·단계 이동·키보드·부드러운 카메라·병렬 연결 애니메이션·패널 경계·다크모드·오프라인 검사도 통과했다. 위치·스키마 일치만으로 문장 의미나 사람의 이해를 승인하지 않는다.

## 확인할 결과와 재현

최종 확인 파일은 **`build/eval/m5-final/agent-project.html`**이다. 책임 구역을 펼치거나 주요 기능에서 **도구 병렬 처리와 실패 경계**를 선택한다. **동작 설명 → 규칙과 이유 → 프로젝트 지도** 순서로 이동하면 처음 선택한 지도 위치로 돌아온다. **명령으로 에이전트 시작**은 미생성 상세 요청을 확인하는 예다.

사용자의 원격 확인 요청에 따라 최종 지도 6개와 연결되는 상세 18개를 [eval/m5/html](../m5/html/)에도 그대로 보존했다. 각 HTML과 동일한 render JSON을 포함하며 페이지 간 상대 링크를 확인했다. 복사한 경로에서 M5 브라우저 검사 40개도 통과했다. [GitHub 미리보기와 파일 안내](../m5/README.md)에서 화면을 보거나 다운로드할 수 있다. 이 보존본은 생성 템플릿으로 사용하지 않는다.

이 폴더는 이전 동작·규칙을 새 템플릿으로 재생성한 회귀 자료와 M5 지도가 함께 있는 의도적인 평가 묶음이다. `*-project.html` 여섯 개가 M5의 새 지도다. 총 37개 HTML에는 기존 30개와 새 지도 6개, 유틸리티 지도의 입력 계약 규칙 동반 페이지 1개가 있다. 동반 페이지는 별도 독립 생성 사례로 세지 않는다.

~~~sh
npm run eval:atlas -- --output build/eval/m5-next
S2S_EVAL_DIR=build/eval/m5-next npm run test:browser
npm test
npm run eval:compare -- eval/runs/2026-09-07-m4.json build/eval/m5-next/results.json --allow-suite-extension
~~~

재실행은 새 출력 경로를 사용한다. `build/eval/m5-draft`, `m5-check`, `m5-ui*`, `m5`는 개발·검증 중간 실행을 보존한 경로다. `build/examples/` 11개와 `build/m1/` 6개도 0.6.0 공통 템플릿으로 재생성했다. 기존 M4 출력과 사람 검토 답변은 덮어쓰지 않았다. 전체 산출물은 Git 제외 build에, 선택한 실행 기록·스크린샷은 eval에 둔다.

[소스 읽기 기록](../m5/discovery.md)과 [사용 안내](../../docs/project-maps.md)에 실제 지원 범위를 남겼다. M0–M5의 계획된 구현은 갖췄으며, 독립적인 사람 검토·승인 베이스라인·최종 IR 확정은 남아 있다.
