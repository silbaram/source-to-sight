# M2 자동재생 표시 수정 — 2026-09-06

이 문서는 진행 표시를 보완한 시점의 기록입니다. 이후 [병렬 구간 진입·호출 연결 수정](m2-parallel-handoffs-verification.md)에서 3→4단계의 이동 누락도 해결했습니다. 이 문서의 실행은 `build/eval/m2-before-parallel-handoffs/`에, 최신 결과는 `build/eval/m2/`에 있습니다.

`agent-parallel-tools.html`의 기본 시나리오를 연속 재생해 확인했습니다. 단계 전환은 진행됐지만 8단계 중 이동 점이 나오는 단계는 2개뿐이었습니다. 병렬·연결 없는 구간에는 진행 표시가 없어 멈춘 것처럼 보였고, 첫 노드 단계에서 지도 일부가 화면 위로 가려졌습니다. 일시 정지 후 재생하면 현재 단계의 이동과 대기 시간을 처음부터 시작하는 문제도 확인했습니다.

## 변경

- 모든 단계에 설명 진행 막대와 준비·설명 중·일시 정지·완료 상태를 표시합니다.
- 이동 점을 사용할 수 없는 단계는 현재 설명하는 노드에 방향 없는 강조 효과를 표시합니다. 병렬 구간은 별도 문구로 알리고, 미확인 근거의 색상과 기존 관계 방향을 유지합니다. 이 강조는 설명 위치이며 작업별 실행 순서를 뜻하지 않습니다.
- 노드 단계에서도 재생 시작 시 지도를 화면 안으로 가져옵니다.
- 일시 정지는 강조·이동을 멈추고 진행률을 보존합니다. 마지막 단계를 포함해 남은 시간부터 이어 재생하고, 완료 후 재생은 처음부터 시작합니다.
- 모션 감소 설정에서는 움직임 없이 단계별 진행률과 현재 위치를 표시합니다.

공통 템플릿을 수정하고 `build/examples/` 11개, `build/m1/` 6개, `build/eval/m2/` 24개 HTML을 갱신했습니다. 이전 M2 실행과 검토 답변은 `build/eval/m2-before-playback-fix/`에 보존했습니다.
