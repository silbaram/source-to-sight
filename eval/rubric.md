# M1.5 evaluation rubric v1

이 기준과 18개 정답 후보는 **독립적인 사람 검토 전**입니다. `confirmed`는 위치 검사와 작성자의 근거 판정을 반영하며, 사람의 승인이나 문장 전체의 진실성을 뜻하지 않습니다.

| 축 | 자동 검사 | 사람의 통과 판정 |
| --- | --- | --- |
| 대상·범위 | 고정 저장소/커밋, 질문, 대상, 범위, 프로파일, 언어 일치 | 질문에 답하고 범위 밖 기능을 분석했다고 주장하지 않음 |
| 구성·관계 | 역할과 소스 위치로 필수 노드, 관계 방향·유형·확신 수준 비교 | 누락·과잉·순서 오류 없음. 추가 요소도 근거 확인 |
| 근거 | 실제 파일 해시·앵커·줄 범위 재검사 | 근거 내용이 요약·관계·캡션을 뒷받침함 |
| 설명·규칙 | 미해소 상태, 불확실성, 명시적 금지 관계 검사 | 조건·숫자·단위·반환·실패·종료가 정확함 |
| 이해 가능성 | 자동 판정하지 않음 | 처음 보는 독자가 목적·입력·결과·핵심 동작·한계를 설명함. 핵심 동작을 거꾸로 이해하지 않음 |
| 범용성 | 6유형 × 일반/경계/최소 또는 동적, 3언어 분포 검사 | 억지 웹 계층이나 불필요한 순서·재생을 넣지 않음 |

## 자동 점수와 한계

- 역할은 `kind`, 허용 `codeName`, 지정 파일·줄을 포함하는 근거 범위로 대응시킵니다. 노드 ID·표시 문구는 비교하지 않습니다. 동일 역할에 여러 노드가 맞거나 한 노드가 여러 역할에 재사용되면 실패합니다.
- 필수 노드/관계 재현율 = 대응된 수 / 정답 후보의 필수 수. 관계가 없는 사례의 관계 재현율은 N/A입니다. 위치와 확신 수준은 별도 실패 항목입니다.
- 자동 비교는 명시된 기준만 검사합니다. 추가 노드·관계는 결과 JSON에 따로 남기고 사람이 확인합니다. 허용 이름이 다른 동등한 구현 분해도 검토가 필요하며, 이를 자동으로 의미 오류라고 단정하지 않습니다.
- `requiredFacts`와 `forbiddenClaims`는 문장 검색으로 채점하지 않습니다. 사람은 본문·규칙·시나리오·추가 요소 전체를 읽고 각각 판정합니다. 정답 후보 수정에는 별도 검토가 필요합니다.
- 존재하지 않는 관계의 확정, 수치·조건 오류, 무근거 확정은 치명적 오류입니다. 자동으로 검출한 항목과 사람이 `criticalErrors`에 기록한 항목을 모두 보고합니다. 자동 검출 0건은 의미 오류 0건의 증명이 아닙니다.

## 사람 검토와 게이트

매 실행은 답을 채우지 않은 `<case-id>.review-template.json`을 만듭니다. 검토자는 정답 후보를 고정 소스와 대조해 `reference`를 판정하고, 실제 생성 HTML의 `candidate`를 별도로 판정합니다. 서로 독립적인 검토가 권장됩니다. `facts`는 필수 사실이 맞고 포함되어야 pass, `forbidden`은 금지 주장이 없어야 pass입니다. 각 배열의 번호는 정답 파일의 순서와 같습니다.

`reference`와 `candidate`에 검토자·시간대가 있는 ISO 시각·결정을 적습니다. 후보의 6개 축, 모든 필수 사실과 금지 주장 판정을 채우고, 치명적 오류는 구체적으로 기록합니다. 검토 파일은 후보·정답·렌더러/지침/평가 코드/이 루브릭의 해시에 묶입니다. 변경 후 이전 승인은 `stale`로 실패하며 재검토해야 합니다. IR의 `humanReviewed` 자기 표기만으로 승인하지 않습니다.

18건 모두 자동 검사와 사람 검토를 통과해야 전체 `passed`입니다. 미검토는 `pending-review`, 일부 실행은 `incomplete`, 검출 오류는 `failed`입니다. 기본 명령은 자동 검증 성공 시 미검토라도 종료 코드 0을 반환하지만 `--strict`는 전체 승인까지 실패합니다. 코드 1은 평가 실패/엄격 게이트 미충족, 2는 설정 또는 입출력 오류입니다.

## 실행·비교 기록

유형별 자동 통과 수·승인 수·노드/관계 재현율·실패 유형과 사례별 결과를 공개합니다. 생성 시간·토큰·비용·모델을 실제로 측정하지 않았다면 null입니다. 평가 실행 시간과 근거 파일·중복 제거 줄 수는 따로 측정하며, 후자는 전체 탐색량이 아닙니다. 현재 기준 실행은 저장된 후보 재검증이고 독립 모델 생성 평가가 아닙니다.

비교는 사례 누락, 필수 요소 손실, 새로운 실패, 치명적 오류, 기존 승인 상실을 찾습니다. 정답·평가 구성·소스가 바뀌면 비교 불가를 표시합니다. 평균이 좋아져도 개별 유형 실패를 가리지 않습니다. `no-regression`은 전체 게이트 통과를 뜻하지 않습니다.

공통 지침 변경은 유형별 최소 1건과 과거 실패 사례, 프로파일 변경은 해당 유형 3건과 다른 유형 최소 3건, 스키마·공통 렌더러·검증기 변경은 18건 전체를 실행합니다. `--case`는 선택 기능이며 이 최소 집합을 자동 선택하거나 정책 충족을 보증하지 않습니다. 사람 승인 베이스라인 확정 전에는 IR 동결·M1.5 완료를 선언하지 않습니다.
