# M0 구현 및 검증 기록

검증일: 2026-09-06. [v5 개발 계획](../plans/source-to-sight-evolution-plan.md)의 M0를 구현하고 코딩 에이전트가 자동 검사와 브라우저 화면 확인을 수행했다. 전체 고도화나 사람 검토의 완료 기록은 아니다.

같은 날 후속 검토에서 발견한 스냅샷 비교, 상태 조건, 구역 검증 표시 문제를 수정하고 다시 검증했다. 아래 테스트 수는 수정 후 결과다. 수정 전 재현과 해결 기록은 [M0 리뷰](m0-review.md)에 있다.

## 구현 결과

| 계획 항목 | 결과와 근거 |
| --- | --- |
| S0.1 제품 지침 | `visual-primer`의 대상 코드 본문 노출 지침을 제거했다. 세 계층의 역할, 사용자 언어, 범위 유지 원칙을 명시했다. 기존 스킬의 구조 검사도 통과했다. |
| S0.2 IR·검증기 | 내부/출력 JSON Schema 0.1.0과 의미 검증기를 구현했다. ID·참조·문맥 노드·근거 상태를 검사하며 HTTP나 DB를 필수로 요구하지 않는다. 두 스키마는 생성 스크립트로 동일하게 재현된다. |
| S0.3 픽스처 | 총 11개. 실제 코드 기반은 JavaScript 유틸리티, Python 플러그인 프레임워크, Python AI 에이전트의 3유형이다. 합성 자료 및 같은 유틸리티를 재사용한 지도·규칙 예시를 구분했다. 출처와 범위는 [픽스처 목록](../fixtures/manifest.md)에 기록했다. |
| S0.4 레이아웃 | 동일한 렌더러로 선형·분기·합류·반복·등록·의존·데이터 관계를 표현한다. 노드 1개, 시나리오 0개도 정상 결과다. 큰 그래프는 글자를 축소하지 않고 그림 영역 안에서 스크롤한다. |
| S0.5 상호작용 | 노드/연결 선택, 설명·근거 패널, 이전/다음/자동 재생, 시나리오 전환, 핵심/상세 보기를 구현했다. 세부 동작과 상태 변경 조건도 표준 픽스처에서 검증한다. 실행 순서가 없는 관계도에는 재생을 만들지 않는다. |
| S0.6 신뢰·연결 | 원본 파일·줄·앵커·해시를 다시 확인한다. 검토 해시와 현재 관측 해시, 위치 확인과 작성자의 내용 검토를 구분한다. 실패한 근거와 부분적으로만 일치하는 미커밋 스냅샷은 같은 소스로 판정하지 않는다. 지도 구역의 자체 검증 상태와 근거도 표시한다. 실제 재탐색은 M1 범위다. |
| S0.7 렌더링 QA | Chromium의 1440×1000 및 390×844 화면에서 오프라인 렌더링·조작을 검사했다. 아래 스크린샷은 해당 실행에서 저장하고 직접 확인한 화면이다. |
| S0.8 출력 경계 | 출력 스키마가 `anchorText`와 코드 본문 필드를 금지한다. 픽스처 원문 앵커 누출을 검사했고, HTML 종료 태그·스크립트·이미지 이벤트·따옴표가 실제 브라우저에서 실행되지 않고 텍스트로 남는 것을 확인했다. |

프로젝트 유형별 렌더러 분기는 없다. `profiles`는 탐색 메타데이터이며, 화면은 공통 노드·관계·시나리오·검증 상태를 사용한다.

## 실행 결과

| 검사 | 결과 |
| --- | --- |
| `python3 scripts/fetch_fixture_sources.py` | 공개 저장소 3곳의 고정 커밋 파일을 다운로드하고 픽스처의 SHA-256과 대조 |
| `npm run fixtures` | 오프라인 HTML 11개 생성 |
| `npm test` | Python 검증 테스트 28개 통과 |
| `npm run test:browser` | 데스크톱·좁은 화면 브라우저 테스트 48개 통과 |
| `s2s.py inspect build/examples/agent-run.html` | 대상 ID·질문·언어·재생성 명령 추출 확인 |
| 기존 스킬 `quick_validate.py` | `visual-primer` 유효 |

브라우저 검사는 외부 HTTP 요청과 실행 오류가 없음을 확인하고, 본문 가로 넘침·노드 겹침·관계선의 다른 노드 관통·연결선 양끝의 접점을 검사한다. 재생 중 상세 노드 노출, 마지막 단계 정지, 모바일 패널과 키보드 포커스, 로컬 페이지 이동, 한국어/영어 조작 문구도 검사한다.

검사 과정에서 모바일 패널이 재생 버튼을 가리는 문제, 레이아웃 엔진의 자기 반복선 접점 오류, 기본 폰트에 한글이 없는 환경의 글자 깨짐을 발견해 수정했다. 한국어 폰트와 레이아웃 엔진은 라이선스와 함께 HTML에 포함한다.

## 남은 범위

이 버전은 검토한 IR을 HTML로 만드는 기반이다. 실제 코드 픽스처의 주장은 고정 소스를 읽고 작성했으며, 임의의 저장소를 자동으로 분석했다고 주장하지 않는다. 합성 웹·CLI·라이브러리·데이터 사례는 해당 유형의 실제 탐색 성공으로 세지 않는다.

위치·해시·참조 검사는 자연어 설명의 진위를 자동으로 증명하지 않는다. 코드처럼 보이는 텍스트 차단도 보조 검사이므로 작성 단계의 검토가 필요하다. 실제 세 저장소의 근거는 에이전트가 검토했으며 독립적인 사람 검토는 아직 없다.

다음 M1은 `code-flow/SKILL.md`, 공통 탐색 절차, 유형별 프로파일, 여섯 유형의 실제 저장소 출력과 사람 검토다. M1.5 이후의 골든셋, 전체 규칙 탐색, 프로젝트 지도 탐색도 후속 개발 범위다.
