# 배포 파일 기준

이 저장소는 실행 가능한 스킬과 사용자 안내, 대표 예시를 관리합니다. 검증기와 생성 명령의 최소 회귀 검사는 저장소에서 유지하고, 평가 입력·실행 결과·시안은 별도 개발·검증 작업 공간에서 관리합니다.

## 제품 배포 범위

다음 경로가 실제 사용자에게 제공되는 제품입니다.

- `skills/code-flow/`: 소스 기반 동작 설명 스킬, 렌더러, 스키마, 참고자료와 라이선스
- `skills/visual-primer/`: 개념·규칙 설명 스킬과 화면 템플릿
- `skills/codebase-atlas/`: 프로젝트 지도 생성 스킬
- `README.md`, `README.ko.md`, `docs/`: 설치·사용·지원 범위와 배포 기준 안내
- `assets/`: 저장소에서 바로 열어 볼 수 있는 대표 예시

스킬을 설치할 때는 각 `skills/<name>/` 디렉터리를 통째로 포함해야 합니다. `templates/vendor/`의 폰트·Dagre 파일과 라이선스도 런타임 렌더링에 필요하므로 제외하지 않습니다.

`skills/code-flow/scripts/vendor/`의 Python 검증기와 라이선스도 필수입니다. 이 검증기는 스킬 실행에 사용되며 생성 HTML에는 포함되지 않습니다.

## 개발·검증 보관 범위

검증기 교체의 안전망인 최소 회귀 검사와 대조 방법은 [검증 안내](../tests/README.md)에 있습니다. 이 검사들은 스킬 설치 대상이 아니며, 실행 결과는 임시 작업 공간에 생성합니다.

다음 종류의 과거 개발·검증 보관물은 제품 브랜치에서 제거했으며 별도 작업 공간에서 관리합니다.

- 평가 manifest·그래프·정답·검증 보고서·QA 스크린샷
- fixture와 고정 소스 출처
- 과거 평가 실행 도구와 대규모 회귀 검사
- 개발 계획·UI 시안·프로토타입
- 개발 환경과 검사 실행 설정

과거에 생성된 HTML·JSON은 제품 템플릿이 아닙니다. 생성기의 기본 템플릿은 `skills/code-flow/templates/flow-viewer-template.html`과 `skills/visual-primer/templates/`에 있습니다.

## 생성 결과와 배포 결과 구분

생성되는 HTML·render JSON·스크린샷은 대상 프로젝트의 별도 작업 공간에 두고 제품 저장소에는 커밋하지 않습니다. 스킬 설치에는 위 제품 배포 범위의 스킬 디렉터리를 제공합니다.

`git archive`는 최소 회귀 검사를 포함해 지정한 커밋의 추적 파일 전체를 소스 묶음에 포함합니다. 현재 `.gitattributes`에는 외부 라이선스와 벤더 파일의 공백 검사 예외만 있으며, 별도의 `export-ignore` 규칙은 없습니다. 과거 개발·검증 보관물은 제품 브랜치에서 이미 제거했습니다. 생성 결과와 검증 기록은 대상 프로젝트의 별도 작업 공간에서 관리합니다.
